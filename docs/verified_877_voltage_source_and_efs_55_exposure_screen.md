## Next experiment: actual EFS source years with hypothetical bus-share screen

Code: `src/energy_transition/efs_55_positive_pd_candidate_exposure.py`, tests: `tests/test_efs_55_positive_pd_candidate_exposure.py`, workflow: `.github/workflows/efs-55-positive-pd-candidate-exposure.yml`.

The experiment reads **only existing archived real-source datasets**: original network from run 41531397166, and official NLR EFS 11-state hour data from run 41265678862. It guards the complete 11 × 3 × 8,760 original hourly keys. For each of the 55 zero-degree, original positive-Pd buses it matches the **exported** bus state to the EFS source state and multiplies the annual state demand by that bus's original `LAF_state`. This estimates a **hypothetical source LAF exposure** across 2030/2040/2050, not a confirmed physical load allocation.

The source `full_state` normalization key has been dropped from the original network, two state-boundary cases have documented discrepancies, and physical UTC alignment, ReEDS receiving-zone semantics and electrical bus service are not independently admitted. Accordingly the diagnostic must never be reported as actual stranded demand or power flow, and its output must be labelled a **candidate exported-state/LAF combination**, not verified generation adequacy.

The CI archives `55_positive_pd_candidate_efs_state_annual_exposure.csv` and a source cohort summary JSON and explicitly asserts zero approved generator POIs, zero verified loss-of-load, and no complete Western OPF. The screen's numerical output should be treated as pending until this new CI has succeeded.

## Research implications

An immediate blind deletion of all zero-degree nodes would be unsound: 55 nodes retain original positive source `Pd`, and 720 non-offshore nodes have preserved source LAF attributes. The next decision should be whether the original dataset represents generator terminal, auxiliary, or intentionally dangling nodes, checked against the raw node/branch creation rules and real source machine/transformer tables. Only then should pruning or reconstruction and full 2030–2050 physical dispatch be contemplated.
